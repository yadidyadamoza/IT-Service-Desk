# 📊 IT Service Desk – Executive Performance Dashboard

## 📌 Overview
An executive-level performance dashboard built in **Power BI** to monitor IT Support Operations, track key service desk metrics, and evaluate ticket distribution across corporate departments.

## 🛠️ Tech Stack & Methods
* **Visualization:** Power BI Desktop
* **Data Source:** Excel (`IT_ServiceDesk_Data.xlsx`)
* **Data Modeling & DAX:** Measures calculated for SLA rates, ticket counts, and satisfaction scores (CSAT).

## 🔑 Key Metrics & Insights
* **SLA Met Rate:** Achieved **100.00%** compliance rate for ticket resolution within agreed target times.
* **Volume Analysis:** Tracked and categorized **19 total tickets** across organizational departments.
* **Service Quality:** Maintained an Average Customer Satisfaction (CSAT) score of **4.44 / 5.0**.
* **Department Breakdown:** R&D and Sales generated the highest volume of IT support requests.
